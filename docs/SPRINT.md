# LOCUS Sprint Plan

## Current Sprint: Sprint 00 — Foundation

### Goal

Create a clean engineering foundation before implementing the visual product.

### Scope

- initialize Next.js + TypeScript project
- establish directory structure
- define core TypeScript interfaces
- configure linting
- configure test framework
- create minimal app shell
- create CHANGELOG.md
- ensure lint, tests, and build pass

### Do Not Build Yet

- 3D globe
- external APIs
- cultural matching
- AI generation
- MapLibre walk mode
- authentication
- payments
- social features

### Acceptance Criteria

- project runs locally
- TypeScript strict mode enabled
- lint passes
- tests pass
- production build passes
- core domain interfaces exist
- documentation remains intact
- no unnecessary dependencies
