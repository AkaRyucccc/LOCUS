# LOCUS UX Flow

## Flow 001 — First Open

1. Black screen
2. Coordinates appear briefly
3. Cinematic 3D Earth fades in
4. Earth rotates slowly
5. Cultural labels and geographic coordinates float over selected locations
6. Main prompt appears: **WHERE ARE YOU?**
7. User enters latitude and longitude, or later chooses device location
8. User taps **FIND ME**
9. Earth rotation accelerates
10. Camera flies toward target coordinate
11. Target locks
12. Geographic pulse appears
13. Location name and coordinates appear
14. System begins cultural scan
15. Candidate cultural memories appear
16. Rejected candidates fade out
17. Winning cultural match remains
18. User sees **MATCH FOUND**
19. User taps **ENTER THE SCENE**
20. Immersive scene plays
21. User is presented with the next nearby memory
22. User can walk toward it

## Core Loop

Location
→ Match
→ Scene
→ Walk
→ Next Memory

## MVP UX Rule

The first 8–10 seconds must be compelling enough to stand alone as a shareable product moment.
