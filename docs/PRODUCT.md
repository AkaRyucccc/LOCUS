# LOCUS Product Definition

## Mission

LOCUS turns physical locations into portals to cultural memory.

## Core Experience

WHERE ARE YOU?
→ 3D Earth
→ Location Lock
→ Cultural Scan
→ Cultural Match
→ Enter Scene
→ Walk
→ Discover

## User Role

The user is always **The Observer**.

The user does not replace historical, literary, or artistic characters. The experience is first-person and observational.

## Product Feel

LOCUS should feel like:

- Museum
- Cinema
- GIS
- Exploration
- Cultural discovery
- Geographic mystery

LOCUS should not feel like:

- Google Maps
- TripAdvisor
- Wikipedia
- A generic tourism guide
- A SaaS dashboard
- A generic AI chatbot

## MVP

The first MVP focuses on London.

MVP scope:

1. Cinematic 3D Earth opening
2. Latitude / longitude input
3. Programmatic fly-to
4. Location lock
5. Cultural candidate retrieval from a curated local dataset
6. Deterministic cultural matching
7. Match reveal
8. Pre-generated immersive scene
9. Simple city-walk continuation to the next cultural memory

## Non-goals for MVP

Do not build:

- live AI video generation
- social networking
- payments
- profiles
- chat
- AR
- creator marketplace
- global city coverage
- complex personalization

## Core Product Principle

The key emotional moment is:

**I am standing here, and I did not know this place contained this story.**
