# LOCUS Design System

## Design Direction

Keywords:

- cinematic
- geographic
- mysterious
- premium
- archival
- atmospheric
- minimal

## Avoid

- generic SaaS cards
- excessive rounded rectangles
- bright startup gradients
- dense navigation
- dashboard layouts
- playful cartoon UI
- generic travel-app aesthetics

## Visual Hierarchy

1. Earth / scene
2. Geographic coordinates
3. Cultural title / creator
4. Supporting interface

## Base Palette

- Background: near-black
- Primary text: white
- Secondary text: muted white / grey
- Accent: restrained geographic signal color
- Artwork scenes may inherit colors from source material

## Typography

Use a clean modern sans-serif for interface text.

Coordinate displays may use a technical or monospaced treatment when appropriate.

## Motion

Motion must feel controlled and cinematic.

Preferred:

- slow rotation
- deliberate acceleration
- smooth deceleration
- subtle atmospheric movement
- geographic pulse
- slow dissolves

Avoid:

- camera shake
- excessive bouncing
- fast UI transitions
- arbitrary animation

## Mobile-first

Primary design viewport: 390 × 844.

Also verify:
- 375 × 667
- 430 × 932
